# macOS Input Source Icons

1. **Create an Language Icon image**

    Original PNG files were created with [https://icon.kitchen/](https://icon.kitchen/) website and export with 512x512 pixels.

2. **Resize an image**

    Resize PNG images to 32x32 pixels size with [https://www.iloveimg.com/](https://www.iloveimg.com/) website.

3. Create `.incs` file

    Convert PNG file to `.incs` file with [https://cloudconvert.com/](https://cloudconvert.com/) website.
