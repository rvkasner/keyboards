# Kasner Keyboard Layouts for macOS

This repository contains custom keyboard layouts designed for personal productivity on macOS. It includes optimized configurations for both English and Russian languages, packaged into a single bundle for easy installation.

## Contents

The repository provides a **macOS Keyboard Bundle** (`.bundle`) containing the following input sources:

- **Kasner En**: Custom English layout.
- **Kasner Ru**: Custom Russian layout.
- **Kasner Uk**: Custom Ukrainian layout.

Both layouts feature custom icons in `.icns` format to ensure seamless integration with the macOS menu bar.

## Installation

Follow these steps to install the layouts on your Mac:

### 1. Download the Layout

Clone this repository or download the layout files directly. Locate the `Kasner 2026 Mac Keyboard Layouts.bundle` file inside the project directory.

### 2. Install the Bundle

Copy the bundle file to your user's **Keyboard Layouts** directory.

1. Open **Finder**.
2. Press `Cmd + Shift + G` (or select *Go -> Go to Folder* in the top menu).
3. Paste the following path and press Enter:

    ```bash
    ~/Library/Keyboard Layouts/
    ```

    > This path is pointed to the current user home directory.

4. Drag and drop the `Kasner 2026 Mac Keyboard Layouts.bundle` file into this folder.

> Note: If you want the layout to be available to all users on the computer, copy it to `/Library/Keyboard Layouts/` instead (it requires Administrator password).

### 3. Log Out / Restart (Recommended)

macOS often requires a logout or restart to recognize new keyboard bundles properly.

- **Log out** of your user account and log back in, **OR**
- **Restart** your computer.

### 4. Activate the Layout

Once you have logged back in:

1. Open **System Settings** -> **Keyboard**.
2. Click the **Edit...** button next to **Input Sources**.
3. Click the **+** (Plus) button to add a new layout.
4. Scroll down to the **Others** category (or look under English/Russian).
5. Select **Kasner En** or **Kasner Ru** and click Add.

## Development & Editing

These layouts were created and are maintained using **Ukelele**, a Unicode Keyboard Layout Editor for macOS.

### Requirements for Editing

- Ukelele (latest version recommended).

### File Structure

- The layouts are encapsulated within a `.bundle` file generated by Ukelele.

- **Icons**: The layouts use custom icons in `.icns` format.
    * **Dimensions**: 32x32 pixels.
    * If you plan to modify the icons, ensure they adhere to macOS icon standards and are re-imported via Ukelele or manually placed inside the bundle resources.

### How to Edit

1. Open Ukelele.
2. Go to **File** -> **Open** and select the `.bundle` file from this repository.
3. Make your changes to the key mappings.
4. Save the bundle and reinstall it using the instructions above.

## Troubleshooting

The layout does not appear in the Input Sources list.

- Ensure the file is in `~/Library/Keyboard Layouts/`.
- Try restarting your computer. macOS caches keyboard layouts, and a restart forces a refresh.

The icon is not showing.

- Ensure the `.icns` files are correctly linked within the bundle.
- If you edited the icon, verify it is `32x32` pixels.
