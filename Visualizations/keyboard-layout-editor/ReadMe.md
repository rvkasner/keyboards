# 🎨 Layout Visualization

[https://www.keyboard-layout-editor.com/](https://www.keyboard-layout-editor.com/)

To visualize the keyboard layouts or generate schematic images, use the [Keyboard Layout Editor](https://www.keyboard-layout-editor.com/).

## How to View

You can access the visualizations in two ways:

### 1. Via GitHub Gist

1. Log in to the website using your GitHub account (**rvkasner**).
2. Use the **My Layouts** menu to open the layouts saved directly to your account (*GitHub Gist*).

### 2. Via Repository Files

1. Use the `.json` layout files provided in this repository.
2. Upload the file content (or copy-paste the JSON code) directly into the editor on the website.

## 🖼 Exporting

Once the layout is loaded, you can generate a visual representation by selecting **Download** -> **Download PNG** from the site's menu.
