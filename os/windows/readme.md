# Kasner Keyboard Layouts for Windows

The Kasner layouts for Windows are packaged from the `.klc` source files and generated with **Microsoft Keyboard Layout Creator 1.4 (MSKLC)**. Each language variant — English, Russian, and Ukrainian — has its own compiled installer inside [kasner-layouts-installers.zip](kasner-layouts-installers.zip).

## Installation Notes

1. Extract `kasner-layouts-installers.zip`.
2. Run the installer that matches the language layout you need.
3. Complete the installation wizard.

> ⚠️ **Windows 11 quirk:** Immediately after running the installer, Windows 11 may misbehave when switching layouts (layouts appear but do not activate correctly).
>
> - If the issue appears, fully restart the computer first. 
> - For a more reliable fix, remove the newly added layouts from **Settings → Time & language → Language & region → Keyboards**, restart Windows, and then add the Kasner layouts back manually for each language. After the reboot-and-readd cycle, the layouts show up consistently and switching works as expected.
>
> These steps ensure the Kasner layouts integrate cleanly and remain stable on Windows 11.
